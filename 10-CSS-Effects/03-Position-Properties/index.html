CSS Position Properties

1. Static

Position: static

Static is the default position of an element.

2. Relative

Position: relative

This element is moved relative to its normal position.

3. Absolute

Position: absolute

The absolute element is positioned relative to its nearest positioned ancestor.

4. Sticky

Position: sticky

Scroll the page to observe the sticky element.
